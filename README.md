# Dr. James Gordon — Eye & Face Cosmetic Surgery

Professional website for Gordon Eye & Face cosmetic surgery practice.

## Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Styling:** Tailwind CSS v4
- **Animations:** Framer Motion
- **Image Storage:** Supabase
- **Hosting:** Vercel

## Development

```bash
npm install
npm run dev
```

Site runs on http://localhost:3000

If `3000` is already forwarded or stuck in your IDE, use:

```bash
npm run dev:3001
```

Then forward `localhost:3001` instead.

## Production

Deployed via Vercel at:
- https://jamesgordon.vercel.app
- https://drjamesgordon.com

## Gallery

309 cases across 13 procedures, all images optimized as WebP and stored in Supabase.
